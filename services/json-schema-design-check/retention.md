# Retention — json-schema-design-check

Per-deliverable pricing retains through repeat need: the buyer's work regenerates the same deliverable need on a cadence (each release, each report cycle, each new case).

**Our own repeat use:** Product API payload schema design — the workflow recurs in our real work, which is the retention pattern external buyers are expected to mirror.

**Churn signal:** trial units issued but not consumed, or a buyer who calls once and never again in 60 days — read at the uptake gates; the response is refine (narrow the service), reprice from measured cost, or retire. Per-atom, never averaged.
