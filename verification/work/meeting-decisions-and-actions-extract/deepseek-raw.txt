# Independent recompute — meeting-decisions-and-actions-extract

## Method / rules applied

From SERVICE.md, the computed quantities are:

- **Counts**: declared list lengths (integer), null if list absent.
- **Row-name lists**: names of rows failing a per-row check (only rows where the field is *present but empty/false*; absent field = missing evidence, not listed).
- **Coverage ratios**: `numerator / denominator`, null when denominator absent/empty (for `inferred_marking_coverage`, null when no decision is inferred).
- **Serialization**: `floor(v * 1000000 + 0.5) / 1000000`, formatted to exactly 6 decimals.
- **computed_status**: `within_stated_limits_on_declared_evidence` if all ten primary computed checks pass; `outside_...` if any fails; null if any cannot be completed.
- **verdict**: SOUND if all 35 pass; NOT_SOUND if any fail; INSUFFICIENT_EVIDENCE if none fail but evidence missing.

The ten primary computed checks: decisions_declared, every_decision_has_source_anchor, every_decision_faithful_to_source, every_inferred_decision_marked, actions_declared, every_action_has_named_owner, every_action_has_due_date, every_action_has_source_anchor, open_questions_declared, every_open_question_has_source_anchor.
