## Rounding rule verification

The rule `floor(v*10000 + 0.5)/10000` then `%.4f`:
- v = −5.0 → floor(−49999.5) = −50000 → −5.0 → `"-5.0000"` ✓
- v = 0.0 → floor(0.5) = 0 → 0.0 → `"0.0000"` ✓
- v = 5.0 → floor(50000.5) = 50000 → 5.0 → `"5.0000"` ✓

All three serialized values reproduce exactly. Note the half-up rule is applied to the *scaled* value before flooring, so negative values round toward +∞ at the half — consistent with the stated formula, and the recorded values are exact integers so no half-case ambiguity arises.
